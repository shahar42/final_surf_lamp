# Design Token Standards

Use these naming conventions for CSS variables to maintain a scalable design system.

## Colors
Format: `--color-{category}-{step}`
- `--color-primary-500`: Main brand color
- `--color-neutral-100`: Backgrounds
- `--color-status-error`: Feedback colors

## Spacing
Format: `--space-{step}`
- `--space-1`: 0.25rem (4px)
- `--space-4`: 1rem (16px) - Base unit
- `--space-8`: 2rem (32px)

## Typography
Format: `--text-{property}-{step}`
- `--text-size-sm`: Small text
- `--text-weight-bold`: 700 weight

## Z-Index
Format: `--z-{layer}`
- `--z-overlay`: 50
- `--z-modal`: 100
