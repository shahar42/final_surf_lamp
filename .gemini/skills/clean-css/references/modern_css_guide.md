# Modern CSS Guide

## Flexbox (1D Layout)
Use for aligning items in a row or column.
- `display: flex`
- `gap`: Spacing between items
- `justify-content`: Main axis alignment
- `align-items`: Cross axis alignment

## Grid (2D Layout)
Use for complex page structures.
- `display: grid`
- `grid-template-columns`: Define columns
- `fr`: Fractional unit for flexible sizing

## Logical Properties
Use logical properties for internationalization support (LTR/RTL).
- `margin-inline-start` instead of `margin-left`
- `padding-block-end` instead of `padding-bottom`
