LED Error Codes

AP
No WiFi
Status: Blinking Red | Left: AP Mode
Open WiFi config portal
Waiting for Data
Status: Solid Green | Left: GREEN
WiFi connected, no server response yet
Server Unreachable
Status: Blinking Orange | Left: GREEN/BLUE
HTTP timeout or 404/5xx error
JSON Parse Error
Status: Blinking Orange | Left: GREEN/YELLOW
Server sent malformed data
Invalid Data
Status: Blinking Red | Left: RED
Wave=0 AND Wind=0 (both sensors zero)
Partial Sensor Failure
Status: Blinking Red | Left: PURPLE
Wave=0 OR Wind=0 (one sensor failing)
Stale Data
Status: Blinking Orange | Left: RED/BLUE
No update received for >30 minutes
SURF
Normal Operation ✓
Status: Blinking Green | Left: Surf data
Fresh data (<30min), displaying conditions
